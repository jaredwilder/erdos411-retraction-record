# Withheld from this archive

This repository publishes the Erdos 411 working record. Six files that were in the first commit
were removed on 2026-09-10 because they are not mathematics.

| file | why |
|---|---|
| `dossier-non_bleach_whitening_technologies_for_safe_daily_use_*.pdf` | A consumer-product invention dossier. Not mathematics, and it carries no row in the author's patent registry, so it is unfiled and unprotected. |
| `CANONICAL_ARCHITECTURE_FULL_SESSION_REPLICATION_DOC.pdf` and `_V2.pdf` and `_V2_BUNDLE.zip` and `canonical_architecture_full_session_bundle.zip` | Method, not result. The document says so in its own header: *"This is not the math paper. This is the operating system for producing the math."* |
| `ORACLE_TO_GPT_EXECUTION_COMPILER_OPERATOR_CARD_BUNDLE.zip` | An operator card for driving a language model to execute that doctrine. Method, not result. |

Everything mathematical stays: the round packets, the coset upper-bound certificates with their
verifiers, the papers, the prime-gap model, and the retraction that supersedes the closure claims.

These files remain reachable in this repository's git history. They are recorded here rather than
removed silently.
